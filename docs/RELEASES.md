# Release information

This public repository is the official distribution channel for AgentOffice. There is no published public-channel installer yet.

A stable Windows release is intended to include the versioned x64 setup executable, its update blockmap and latest.yml. Read its release notes before installing. Update metadata and blockmaps are not installers. The automatically generated GitHub source archives contain distribution documentation, not the application source.

Only official verified installers should be downloaded. A stable version must be validated before publication; the existence of this repository does not imply a working public update feed or a trusted signature on an older build. See [Installation](INSTALLATION.md), [Security](../SECURITY.md), and [Software notice](../NOTICE.md).

For release-specific limitations and changes, refer to the published release notes. Report ordinary problems through [Support](../SUPPORT.md).
