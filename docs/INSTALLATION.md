# Installation and updates

AgentOffice is designed for Windows. The distributed installer is intended for x64 systems. Hardware requirements and supported Windows versions will be confirmed through release-specific testing; no minimum performance guarantee is made here.

## Install

1. Visit the [official Releases page](https://github.com/ENG-mohammed-fares/AgentOffice-Releases/releases).
2. If a stable Windows release is available, select its AgentOffice Setup executable. Do not download the blockmap or update metadata as an installer.
3. Check the release notes and the installer publisher/signature in Windows file properties. If the signature is missing, invalid or unexpected, stop and contact support. Do not disable Windows security protections.
4. Run the verified installer and follow the prompts.

No public-channel installer is available as of the initial documentation publication.

## Updates

Once a compatible public-channel build is published and installed, it is intended to check for stable updates automatically. Updates should not interrupt an active workspace. Actual update behavior depends on the installed version and the release notes.

Older builds that used the previous private release feed may require a one-time manual installation of a newer verified build. Back up important local workspace data before upgrading. Do not uninstall or delete your data to force an update.

For help, see [Support](../SUPPORT.md).
