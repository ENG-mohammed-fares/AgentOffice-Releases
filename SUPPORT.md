# Support

For installation problems, account access issues, visual defects and ordinary bug reports, use the [public issue tracker](https://github.com/ENG-mohammed-fares/AgentOffice-Releases/issues).

Please include your installed AgentOffice version, Windows version, a short description, steps to reproduce and the expected result. Share screenshots only after removing personal information. No response-time guarantee is made.

## Troubleshooting

- No download available: check the official Releases page. The public channel is being prepared.
- An update is unavailable: check your installed version and the current release notes. Older versions may use a previous update channel.
- Sign-in or verification code fails: confirm your network connection and account details; do not share passwords or verification codes. External authentication can depend on provider availability.
- Slow rendering: note your device specifications and graphics settings without sharing device identifiers. Performance can vary with hardware.

Do not post API keys, passwords, session tokens, private project files, full diagnostic dumps or personal data. For suspected vulnerabilities follow [SECURITY.md](SECURITY.md), not a public bug report.
