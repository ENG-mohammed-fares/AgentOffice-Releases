# Security policy

## Supported releases

Security fixes are prioritized for the latest officially published stable release. No stable installer has yet been published through this public distribution channel. Preview and older builds are not guaranteed ongoing support.

## Report a vulnerability

If GitHub offers a private reporting form, use [Report a vulnerability](https://github.com/ENG-mohammed-fares/AgentOffice-Releases/security/advisories/new). Its availability may depend on repository settings.

If it is unavailable, open a minimal [support issue](https://github.com/ENG-mohammed-fares/AgentOffice-Releases/issues) requesting a private security contact, without describing the vulnerability publicly.

In a private report, include the affected version, operating system, component, safe reproduction steps and impact. Redact credentials and personal information. Test only systems and data you are authorized to access. Coordinate disclosure with maintainers.

The maintainers aim to acknowledge reports within seven calendar days; this is a target, not a service-level guarantee. No paid bug bounty or additional license permissions are offered.

Download only official releases. Do not disable Windows protection or trust an unexpected publisher.
