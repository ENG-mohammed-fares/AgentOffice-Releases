# AgentOffice

**A desktop workspace for a virtual software team.**

AgentOffice brings a 3D office and a virtual software team into a Windows desktop application. The project is in active development. The planned autonomous AI employees are not connected yet.

## Download

[Official releases](https://github.com/ENG-mohammed-fares/AgentOffice-Releases/releases)

This is the official public distribution channel. The first public-channel release has not yet been published. When an installer is available, download it from the Releases page, not from the automatically generated source-code archives (those contain this distribution repository's documentation, not the application).
